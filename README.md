# EMBEDDED-PROJECT
# Colour-Based Product Sorting System using Arduino

## Overview

This repository presents the design and implementation of a **Colour-Based Product Sorting System** using an **Arduino Uno**, a **TCS3200 Color Sensor**, and **Servo Motors**. The system automatically detects the color of an object and sorts it into the corresponding bin, demonstrating an embedded automation solution for industrial product classification.

---

## Features

- Automatic color detection using TCS3200 sensor
- Real-time product sorting
- Arduino-based embedded control
- Servo motor actuation for sorting mechanism
- Low-cost and efficient automation system
- Suitable for educational and industrial applications

## Working Principle

1. The TCS3200 color sensor detects the RGB values of the incoming product.
2. The Arduino processes the sensor data and identifies the product color.
3. Based on the detected color, the corresponding servo motor rotates to direct the product into its designated collection bin.
4. The system repeats the process continuously for automatic sorting.
